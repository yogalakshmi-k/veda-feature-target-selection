# Feature and Target Selection

## Project Overview
A Machine Learning beginner project completed as part of the Veda Technology internship.

## Objective
To select suitable input features and a target variable from a Student Performance Dataset.

## Dataset
Student Performance Dataset with 10 records.

## Selected Features
- Study_Hours
- Attendance
- Previous_Marks
- Assignment_Score

## Target Variable
- Final_Marks

## Technologies Used
- Python
- Pandas
- Visual Studio Code

## Conclusion
The selected features represent student academic performance, while Final_Marks is the target variable. This project demonstrates the basic structure of supervised Machine Learning.
